# تسجيلات الأذان في مشكاة

لا مؤذنين مضافين. الصوت الافتراضي لحن مولَّد برمجياً داخل `adhan.js` (مقام الحجاز) من تأليف المنصة، بلا تسجيل لأحد ولا رخصة خارجية، ويمكن للمستخدم اختيار ملف أذان من جهازه فيبقى عليه.
لإضافة مؤذن مستقبلاً: ملف في هذا المجلد ومدخل في `manifest.json` {"id","name","en","country","author","file","license","source"} برخصة CC0 أو PD أو CC-BY أو إذن مكتوب.
