# تسجيلات الأذان في مشكاة

لا يُضاف مؤذن إلا بتسجيل ثابت الرخصة. لإضافة مؤذن:
1. ضع الملف (mp3/ogg/opus) في هذا المجلد.
2. أضف مدخلاً إلى `manifest.json`: `{"id","name","en","author","file","license","source"}`.
3. الرخص المقبولة: CC0-1.0، PD (ملك عام)، CC-BY، CC-BY-SA، أو Own-permission (إذن مكتوب من صاحب التسجيل يُحفظ مرجعه في `source`).
4. تُرفض المدخلات التي تفتقد الرخصة أو المصدر (https) أو المؤذن المسمّى أو كان اسم الملف يخرج عن المجلد.

يُحمَّل الملف عند أول اختيار للمؤذن فقط، ويُحفظ في ذاكرة التطبيق للعمل دون إنترنت، وتظهر بيانات الرخصة في صفحة المواقيت.
